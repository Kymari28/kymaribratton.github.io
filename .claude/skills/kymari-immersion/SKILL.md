# Kymari Immersion

This is the source of truth for KymariBratton.com.

Before making major visual, motion, case-study, or portfolio-content changes, read the reference files in `references/`.

## Priority

1. Strong UX work
2. Clear personal contribution
3. Recruiter usability
4. Art direction
5. Interaction and immersion
6. Decorative delight

Immersion must never hide weak UX, unclear ownership, unreadable content, or unsupported claims.

## Creative direction

The portfolio is:

EDITORIAL first.
LIVING second.
DREAMLIKE third.

Target roughly 50 to 55 percent artistic/experimental while remaining recruiter-safe.

Do not interpret immersive as:

- random parallax
- particles everywhere
- generic 3D
- flowers everywhere
- fantasy UI
- hidden navigation
- constant movement
- excessive hover effects

The portfolio should feel authored, beautiful, organic, technically sophisticated, and alive.

## Experience progression

Protect the existing homepage hero.

The experience progresses:

clear professional hero
→ subtle environmental hint
→ world gradually grows
→ Selected Work becomes project portals
→ hover reveals project personality
→ clicking feels like diving into a project world
→ case study becomes an immersive mini-site

Navigation and information architecture remain understandable.

## Typography

Typography is the anchor.

The world moves around the information.

Do not distort primary text or make paragraphs behave like decorative objects.

## Project worlds

Do not theme the information architecture.

Theme the atmosphere.

Projects may vary in:

- color
- environmental imagery
- material
- motifs
- motion
- visual pacing
- staging
- lighting

Keep familiar:

- navigation
- reading hierarchy
- case-study logic
- controls
- accessibility
- project navigation

## Motion test

Before adding animation ask:

1. Does this make the world feel more alive?
2. Does it communicate something meaningful about this project?
3. Does it improve hierarchy, understanding, depth, or emotion?
4. Does the experience remain understandable without it?
5. Does this still help Kymari get hired?

If not, remove or reduce it.

## Truth

Never fabricate:

- metrics
- usability results
- outcomes
- revenue
- conversions
- clinical impact
- launch status
- users
- grant results
- personal ownership

If evidence is unclear, flag it.

## Copy

Writing should be:

- natural
- specific
- confident
- warm
- human
- concise

Avoid generic corporate UX language.

Do not use em dashes in visible portfolio copy.

## Accessibility

Target WCAG 2.2 AA.

Reduced motion must remain beautiful.

Mobile must be intentionally art-directed rather than treated as desktop with animations removed.
