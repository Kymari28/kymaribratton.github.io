# Motion Language

## Core rule

Motion is storytelling.

Prefer five extraordinary interactions over fifty average animations.

## Motion levels

### Level 0
Static.

### Level 1
Micro interaction.

Examples:

- arrow
- button response
- subtle control feedback

### Level 2
Environmental response.

Examples:

- botanical shift
- shallow pointer depth
- lighting response
- tiny atmospheric movement

### Level 3
Story moment.

Examples:

- data organizing
- guided journey
- image sequence
- environmental reveal

### Level 4
Signature moment.

Rare.

Use approximately once per major project.

A project may earn a second only when the story genuinely benefits.

## Homepage

The hero remains calm.

The site gradually becomes alive.

Idle movement should be extremely restrained.

## Project cards

The outer card remains stable.

Do not rely on generic:

- whole-card translateY
- whole-card scale
- huge hover shadow
- repeated lift animation

Animate internal layers.

Fine-pointer devices may use shallow depth.

Primary device:
approximately ±1 to 1.5 degrees.

Secondary device:
approximately ±1.5 to 2 degrees.

Motif:
small independent or counter movement.

Avoid trading-card tilt.

## Project entry

Clicking should feel like diving into the project world.

Target transition:
approximately under one second.

Do not create an intro screen.

Do not make visitors wait for decorative motion.

Reduced-motion users receive an immediate/simple transition.

## Scrolling

Native scrolling remains under visitor control.

No scroll hijacking.

Allowed when meaningful:

- sticky storytelling
- pinned visuals
- masks
- SVG path animation
- layered depth
- environmental color change
- art-directed section transitions

Start with one major storytelling sequence per flagship case study.

## Case-study hover behavior

Do not reuse About-page card motion inside case studies.

Remove generic box lift, scale, image zoom, and shadow changes when they communicate nothing.

Each case study should have a meaningful project-specific interaction language.

## Project motion personalities

Mindfulness:
slowest, softest, spacious, settling.

GRC:
slightly faster, colorful, energetic, smooth.

Immigrants Rising:
predictable, structural, progress-oriented.

24Seven:
slow cinematic movement.

Brightside:
technical, relational, restrained.

TripTag:
playful and responsive.

We Are One:
warm and comparatively quiet.

## Reduced motion

Reduced motion must remain beautiful.

Disable or simplify:

- pointer tilt
- flying insects
- decorative drift
- path drawing
- large choreography
- parallax

Preserve:

- project atmosphere
- color
- composition
- photography
- hierarchy
- content
