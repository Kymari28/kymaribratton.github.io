# Recruiter UX

Immersion exists in service of the portfolio.

## 10-second test

A recruiter should understand:

- what project this is
- what Kymari did
- what the final design looks like
- why the work matters

## 30-second test

They should understand:

- problem
- role
- important design decision
- major result or learning

## 2-minute test

They should be able to understand:

- research
- process
- decisions
- iteration
- implementation
- results
- reflection

## Case-study hierarchy

Prefer:

Project identity
→ key value or outcome
→ final interface
→ role/team/scope
→ challenge
→ important design stories
→ evidence/testing
→ final experience
→ results
→ reflection
→ next project

Do not begin with a wall of process terminology.

## Visual pacing

Avoid repetitive:

text
text
card
text
card
text.

Prefer:

short context
→ large visual
→ decision
→ visual
→ evidence
→ final UI
→ result.

Avoid placing everything inside rounded cards.

Use editorial composition.

## UI imagery

Actual UX work must remain inspectable.

Do not surround tiny screenshots with giant decorative backgrounds.

Use:

- large UI
- detail crops
- device pairings
- annotations
- sequences
- before/after displays

Never squash device imagery.

## Responsive design

Desktop:
3-column project grid when space supports it.

Tablet:
recompose intentionally.

Mobile:
one-column and no fake hover.

Simplify decoration before shrinking actual project work.
